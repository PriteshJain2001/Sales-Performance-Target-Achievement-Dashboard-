📊 Sales Performance & Target Achievement Dashboard
Overview

This Power BI project provides a comprehensive analysis of sales performance, profitability, target achievement, returns, and delivery delays. The dashboard enables stakeholders to monitor key business metrics, identify trends, and make data-driven decisions through interactive visualizations and KPI tracking.

Objectives
Analyze sales and profit performance.
Track target achievement across different business segments.
Monitor returns and delivery delays.
Compare performance across regions, categories, and managers.
Support strategic decision-making through actionable insights.
Key Features
📈 Sales & Profit Analysis
🎯 Target Achievement Tracking
🔄 Returns Analysis
🚚 Delivery Delay Monitoring
🌍 Region-wise Performance Insights
📦 Category-wise Sales Analysis
📊 Year-over-Year (YoY) Comparison
🔍 Interactive Filters and Drill-Down Analysis
